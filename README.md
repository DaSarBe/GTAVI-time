# GTA 日請假大作戰 🎮

11/19 GTA VI 發售，你的假卻被老闆打槍了……沒關係，上班偷玩就好！

一款在瀏覽器上玩的「老闆鍵」小遊戲：在辦公室偷玩 GTA，聽到老闆的腳步聲就趕快切回 Excel。

## 玩法
- 📅 上市前最後 5 個上班日（11/12～11/18），一天一關，撐到 18:00 下班
- 🎮 偷玩才會推進今天的 GTA 任務，下班前要衝到 100% 才過關
- 🔥 連續偷玩越久倍率越高（×2、×3、×5），一切 Excel 就歸零
- 👂 腳步聲、門上影子 → 快切 Excel（手機點按鈕，電腦按空白鍵）
- 😏 老闆會假走過：真的腳步越來越快、影子越來越大；假的影子會飄過去。越後面越難分辨
- ⏱️ 最後一刻才切，有「好險！」加成
- 💥 一天被抓 3 次就要重來這一天

## 彩蛋
- 🧥 偶爾進門的不是老闆，是仁勳爸爸。被他看到你在玩，DLSS 5 開啟、任務進度 ×2
- 牆上有 NVIDIA 海報，遊戲畫面左上角有「DLSS 5 ON」

## 特色
- 牆上 LED 看板、標題頁、結束頁都有 GTA VI 上市倒數（台灣時間 2026/11/19 00:00）
- 上市後自動改成「已上市 X 天」
- 單一 `index.html`，直接用瀏覽器打開就能玩
